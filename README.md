# studdy

A beautiful, premium study companion that generates personalized study guides, interactive flashcards, and quizzes to help you master any topic instantly.

## Features

- **Tailored Study Guides**: Structured, easy-to-read summaries covering core concepts of any topic.
- **Interactive Flashcards**: Tap-to-flip cards with smooth, fluid animations for active recall.
- **Smart Quizzes**: Dynamic multiple-choice knowledge checks complete with real-time scoring and comprehensive explanations.
- **Modern Dark Aesthetic**: A curated HSL color palette featuring gold highlights (`#C1A57B`), custom typography, and dynamic animations.

## Getting Started

### Prerequisites

You need **Node.js** (v18 or higher recommended) installed on your system.

### Installation

1. Install the required dependencies:
   ```bash
   npm install
   ```

2. Launch the local development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:3000` to start learning.

## Technical Stack

- **Framework**: React 19 with Vite & TypeScript
- **Styling**: Tailwind CSS for premium layouts and typography
- **Animations**: Motion (Framer Motion) for fluid, state-driven transitions
- **Icons**: Lucide React for consistent and crisp vector icons
- **Runtime**: Express for development routing and tsx for execution
